# WrapForge Sample Hatch

Original, deliberately stylized hatchback used as the default vehicle.

- **License:** CC0-1.0 (public domain dedication)
- **Source:** Generated by `tools/generate_sample_vehicle.py` in this repository
- **Generator:** Blender 5.2.0 LTS, background mode
- **Contents:**
  - `model/vehicle.glb` — binary glTF with 13 separate wrap-able panel objects
    and non-wrap glass/light/tyre objects
  - `model/vehicle.blend` — editable Blender source
  - `previews/hero.png`, `previews/thumbnail.png`
  - `manifest.json` — dimensions, panels, UV metadata, license, validation

This is **not** a manufacturer model, scan, or measured production vehicle. Its
proportions are plausible but unverified. Do not use its dimensions for a real
installation without checking the actual vehicle.

Regenerate with:

```bash
blender -b --factory-startup --python tools/generate_sample_vehicle.py -- \
  --out assets/sample-vehicle
```

See [docs/VEHICLE_ASSETS.md](../../docs/VEHICLE_ASSETS.md) for the manifest and
UV conventions.
