# Sample artwork

These SVG files are original artwork created for the WrapForge repository.

- `velocity-stripes.svg` — abstract diagonal stripe composition
- `wrapforge-mark.svg` — geometric WrapForge ribbon mark and wordmark
- `number-07.svg` — racing number composition

License: **CC0-1.0** (public domain dedication). You may copy, modify, and
redistribute them without attribution.

They are deliberately abstract and contain no third-party logos, characters,
trademarks, or fonts that require redistribution. The wordmark text uses the
system/bundled font at render time; outline text before sending artwork to a
printer if exact glyph reproduction matters.
